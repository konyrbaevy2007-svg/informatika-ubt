INFORMATIKA ҰБТ ONLINE v2

Бұл нұсқада:
- оқушы тіркеледі;
- логин/құпиясөзбен кіреді;
- тест нәтижесі ортақ SQLite базаға сақталады;
- оқушылар рейтингі көрсетіледі;
- оқушының жеке кабинеті бар;
- мұғалім барлық оқушының тест саны, үздік және орташа нәтижесін көреді.

МҰҒАЛІМ:
Логин: teacher
Бастапқы құпиясөз: Teacher123!

ІСКЕ ҚОСУ:
1) Компьютерге Node.js 20+ орнатыңыз.
2) Осы буманың ішінде Command Prompt/Terminal ашыңыз.
3) npm install
4) npm start
5) Chrome: http://localhost:3000

МАҢЫЗДЫ:
Оқушылар әртүрлі телефон/компьютерден кіріп, бір ортақ рейтингті көру үшін жобаны интернеттегі Node.js серверіне орналастыру керек.
Онлайн жарияламас бұрын мұғалімнің бастапқы құпиясөзін өзгертіңіз және SESSION_SECRET орнатыңыз.
